# WordWield. Tree Unfolding. Manejo–Materializer

## Core layering

- `o` holds entity, tree, lineage, terraces
- `ww` thinks, acts, and materializes
- materialization belongs to `ww`, not `o`, but is built with `o` intimately

## Materializers

Materializers take tree and materialize it into a medium.
Examples discussed:
- md doc
- webpage
- book
- chapter of a book
- paragraph of a book
- interactive interface
- painting

## Persona and CiiiB

- persona is a materialization
- CiiiB is a materialization

## Manejo

Manejo is the managerial layer between materializer and central `o.tree`.
It holds big picture.
It can answer questions of materializer on more detailed data about this and that.
Manejo takes it and with big picture prompt unfolds new properties on a tree.

Unfold is the term.

## Roles

- `o.tree` — current being / current structure
- Manejo — handles `o.tree` development to produce answers
- materializer — embodies unfolded tree into a chosen medium

## User involvement

Manejo handles `o.tree` development to produce answers.
And to a degree asks user.


## Generated properties and query

Generated properties in `o` can use the tree to build anything that we may query later.
If it is not there, we produce the generated content and then query by it.
That is how it is done.
Not with any SQL.
